## API 契约（P3-A + P3-B）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/comparisons/compare` | body: `left_run_id`, `right_run_id`, `diff_types?` |
| GET | `/api/comparisons/{id}` | 对比详情 + diffs |
| GET | `/api/comparisons?task_id=` | 任务下历史对比 |
| POST | `/api/experiments/task/{task_id}` | 创建/获取实验 |
| GET | `/api/experiments/task/{task_id}` | 任务实验详情 |
| POST | `/api/experiments/{id}/run` | 执行版本对比；**默认** diff：P3 四类 + semantic + structural |
| GET | `/api/tasks/{id}/detail` | 含 `experiment_report` |
