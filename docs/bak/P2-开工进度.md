## 本地启用 PostgreSQL（P2 开发）

```bash
cd onto-eval
docker compose up -d postgres

# .env（WSL 常用 5433）
# DATABASE_URL=postgresql+asyncpg://onto_eval:onto_eval_dev@127.0.0.1:5433/onto_eval_fact
# POSTGRES_PORT=5433

cd backend
pip install -r requirements-dev.txt
alembic upgrade head
uvicorn main:app --reload --port 8000
```

### PG 集成 smoke

**WSL / Linux / macOS**（不要用 `.ps1`）：

```bash
cd backend
chmod +x scripts/run_pg_smoke.sh
./scripts/run_pg_smoke.sh
```

脚本会自动：使用 `backend/.venv`、读取项目根 `.env` 的 `POSTGRES_PORT`、或探测 5433/5432。

**Windows PowerShell**：

```powershell
cd backend
.\scripts\run_pg_smoke.ps1
```

### 分层测试

```bash
cd backend
./scripts/run_all_tests.sh          # L1 默认
PG_ALEMBIC_SMOKE=1 ./scripts/run_all_tests.sh   # + PG smoke
```
