# P2 G-03 — 读路径 / 报表 API 清单

> **目的**：登记所有仍依赖 Langfuse Public API 或 `scan_traces` 的读路径，指导 G-04 迁移与 G-05 降级。  
> **更新**：2026-05-23（P2-B）

---

## 图例

| 读源 | 说明 |
|------|------|
| **FACT** | `agent_runs` + `run_span_nodes` + `run_metrics` + `checkpoint_results`（Execution Fact Layer） |
| **DB** | 编排/评测表（SQLite 或 PG 同库） |
| **LF-SCAN** | `scan_traces()` 分页扫 Langfuse |
| **LF-API** | `LangfuseClient.list_traces` / `get_trace` |
| **OTEL** | onto-eval 内置 OTel 存储（与 Langfuse 独立） |

---

## 1. Trace BFF（`trace_routes.py`）

| 端点 | 默认读源 | 显式降级 | G-04 状态 | 备注 |
|------|----------|----------|-----------|------|
| `GET /trace/facets` | **FACT**（有 `task_id`） | `?source=langfuse` → LF-SCAN | ✅ G-01/G-02 | 无 `task_id` 仍 LF-SCAN |
| `GET /trace/sessions` | **FACT**（有 `task_id`） | `?source=langfuse` → LF-API | ✅ G-04 | 前端 Trace 探索主列表 |
| `GET /trace/traces` | **FACT**（有 `task_id`） | `?source=langfuse` → LF-API | ✅ G-04 | 无 `task_id` 仍 LF-API |
| `GET /trace/traces/{id}` | LF-API | `?source=fact` 或 LF 失败 → FACT | ✅ G-04/G-05 | 详情可读 `run_span_nodes` |
| `GET /trace/tasks/{id}/questions` | **DB** | — | ✅ 已合规 | 数据集 + evaluation_results |
| `GET /trace/projects` | LF 配置 | — | ➖ 配置 | 非报表 |
| `GET /trace/health` | LF 配置 | — | ➖ 探活 | 非报表 |
| `GET /trace/sync-jobs` | **DB** | — | ✅ 已合规 | trace_sync_jobs |

### `scan_traces` 调用点（代码）

| 文件 | 函数/路由 | 触发条件 |
|------|-----------|----------|
| `trace_routes.py` | `get_trace_facets` | 无 `task_id` **或** `?source=langfuse` |
| `trace_facets.py` | `scan_traces` | 被 facets 路由调用（内部分页 `list_traces`） |

## 2. 评测任务 / 报表（`main.py`）

| 端点 | 读源 | G-04 状态 | 备注 |
|------|------|-----------|------|
| `GET /tasks/{id}` | **DB** `evaluation_results` | 🟡 | 雷达图仍算自 results |
| `GET /tasks/{id}/detail` | **DB** + **FACT** 摘要 | ✅ G-04 | 新增 `fact_metrics`（run_metrics 聚合） |
| `GET /stream/{id}` | 内存队列 | ➖ | 非持久化读 |

## 3. 过程点 / Ingest（写为主，只读预览）

| `POST /trace/ingest/*` | 写路径 | 非报表 |

## 6. 前端消费点

| 页面/组件 | API | 期望读源（P2 后） | G-05 |
|-----------|-----|------------------|------|
| Trace 探索 `LangfuseTraceExplore` | `/trace/facets` | FACT（有 task_id） | ✅ 空态/信息条 |
| Trace 探索列表 | `/trace/sessions` | FACT（有 task_id） | ✅ Langfuse 不可用时仍可查 |
| Trace 详情面板 | `/trace/traces/{id}` | LF → FACT 降级 | ✅ 503/404 自动 `?source=fact` |
| 评测结果 `EvalDetail` | `/tasks/{id}/detail` | DB + `fact_metrics` + `analytics_rows`（v_run_analytics） |
| 结果页雷达图 | `/tasks/{id}` | DB（P2 可叠加 fact_metrics） |
